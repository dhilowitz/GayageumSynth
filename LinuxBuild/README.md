# LinuxBuild

Everything in this directory is hand-authored and is **not** regenerated by Projucer. `Builds/`
(including `Builds/LinuxMakefile`) contains only Projucer-generated output, so it's safe to delete the
whole `Builds/` directory to reclaim disk space - nothing in here lives inside it.

## Rebuilding after deleting `Builds/`

1. Open `GayageumSynth.jucer` in Projucer (or run headless: `Projucer --resave GayageumSynth.jucer` -
   safe to run headlessly for this project since it uses `useGlobalPath="0"` with project-relative
   module paths) to regenerate `Builds/LinuxMakefile/Makefile` and `make_helpers/`.
2. From this directory, run `./build.sh` - it calls `apply-patch.sh` automatically first.

## What's here

- `make_static.patch` - patches the Projucer-generated `Makefile`'s Release config to statically link
  most dependencies and hide non-plugin symbols via the linker version script below. No VST2 target -
  GayageumSynth only ships VST3 + Standalone on Linux.
- `symbols/vst3.version` - a linker version script (`-Wl,--version-script=...`) that exports only the
  plugin entry points and hides everything else.
- `apply-patch.sh` - copies `symbols/` into `Builds/LinuxMakefile/` and applies `make_static.patch`.
  Idempotent - safe to re-run, skips the patch if already applied. Run manually any time after
  regenerating `Builds/LinuxMakefile` from Projucer; `build.sh` also calls it.
- `build.sh` - builds both the static and dynamic Linux release variants into
  `Builds/LinuxMakefile/build-static/` and `build-dynamic/`.

Unlike most other Decidedly projects, `Builds/` itself IS committed to this repo (not purely
Projucer-regenerable-on-demand) - that's what lets GitHub Actions CI build directly with no on-runner
Projucer step. Keep that in mind if `Builds/LinuxMakefile/Makefile` ever gets regenerated locally: commit
the result rather than leaving it as an untracked/dirty local diff.
